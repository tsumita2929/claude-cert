# 公開用の文面（YouTube）

動画と一緒に、`video/episodes/<ep>/youtube.md` を作る。ユーザーがそのまま貼れる形にする。

## youtube.md の形

```markdown
# 公開用の文面：<回の名前>

## 題名（案）
1. …
2. …
3. …

## 概要欄
（下の「概要欄の型」のとおり）

## タグ
…, …, …

## アップロードするファイル
- 動画: out/<ep>/<ep>.mp4
- サムネイル: out/<ep>/thumbnail.png
- 字幕: out/<ep>/captions.srt（言語は日本語）

## 公開前の確認
- [ ] …
```

## 題名

- **検索される言葉を前に置く。** 資格名（略称と正式名の両方が検索される）、テーマ、回の番号。
  資格名は `project.json` の `exam`（`short` と `full`）の表記を使う。書かれていなければ、推測せずユーザーに確認する。
  例:「【CCDV-F】Messages API の基本｜必須パラメータは3つだけ（第1回）」
- 全角30字前後まで。長いと一覧で切れる。
- 中身にないことを書かない（「これだけで合格」「完全網羅」など）。期待と違う動画は、すぐ閉じられて評価が下がる。
- 案を3つ出し、違いを一言添える（検索重視、内容の具体性重視、など）。選ぶのはユーザー。

## 概要欄の型

```
（1〜2行で、この動画でわかること。検索結果に出るのはここ）

▼ 目次
0:00 オープニング
0:16 必須パラメータ
…（out/<ep>/chapters.txt をそのまま貼る）

▼ この動画について
・（断り書き。下の「断り書き」を参照）
・内容は ◯年◯月時点の公式ドキュメントに基づいています。

▼ 参考（公式）
・（事実確認で使った一次情報の名前と URL）

▼ クレジット
・音声: （project.json の credit をそのまま。例: VOICEVOX:青山龍星 ／ AivisSpeech（コハク））
・書体: Zen Kaku Gothic New / IBM Plex Sans JP / IBM Plex Mono（SIL Open Font License）
```

- **チャプターは `chapters.txt` をそのまま使う。** 最初が `0:00`、3個以上、各10秒以上が YouTube の条件。
  `voice` が条件を満たさないと注意を出すので、そのときは台本の `chapter` を見直す。
- 参考の URL は、`factcheck.md` に記録した一次情報から選ぶ。

## 断り書き

資格の解説動画では、次を明示する。視聴者を守るためでもあり、チャンネルを守るためでもある。

- **非公式であること。** 試験の主催者が作った、または公認した教材ではないこと。
- **情報の時点。** 仕様や試験範囲は変わるので、いつの情報かを書く。
- **出典が第三者の情報。** 試験の形式・配点・合格点などが公式に公開されていない場合、どこからの情報かと、
  受験前に公式の案内を確認してほしいことを書く。
- **問題は自作であること。** 実際の試験問題ではないこと。

動画の冒頭（`project.json` の `disclaimer`）にも短く出る。概要欄には省略せずに書く。

## クレジットと権利

- **音声。** 声の利用規約が求める文言を、そのまま書く（`voices.md`）。
- **書体。** テンプレートの3書体は SIL Open Font License で、商用の動画に使える。クレジットは義務ではないが、書いておく。
- **Remotion。** 動画の書き出しに使っている Remotion には独自のライセンスがある。個人や小規模な組織は無料で使えるが、
  条件（組織の人数など）は変わりうる。**収益化する前に、公式のライセンスのページで自分が無料の条件に当てはまるかを、
  ユーザー自身に確認してもらう。**（https://remotion.dev/docs/license）
- **試験名・ロゴ。** 試験名を説明のために文字で書くのは問題ないが、主催者のロゴや公式の図版は使わない。
- **BGM・効果音・画像** を足す場合は、収益化した動画で使える素材かを、素材ごとに確かめる。

## サムネイル

`render` が `thumbnail.png`（1280×720）を作る。文字は台本の `thumbnail.headline` と `thumbnail.sub`。

- 大きな文字は**2行まで、1行は全角6字まで**（4字以下がいちばん大きい）。スマートフォンの一覧では切手ほどの大きさになる。
  長いと文字が小さくなる。右側の解答用紙の絵に重なっていないかも、画像で確かめる。
- 題名と同じ言葉を繰り返さない。題名が「何の動画か」を言うなら、サムネイルは「何が得られるか」を言う
  （題名「Messages API の基本」、サムネイル「必須は3つだけ」）。
- 作ったら、Read で開いて確かめる。縮小しても読めるかを考える。

## 公開前の確認（youtube.md に入れるチェック項目）

- [ ] 動画を最初から最後まで、音を出して見た（誤読、アクセント、間）
- [ ] 事実確認の記録（factcheck.md）に、未確認の項目が残っていない
- [ ] 概要欄に、断り書き・情報の時点・クレジットが入っている
- [ ] 声の利用規約と Remotion のライセンスを、公開日の時点で確認した
- [ ] 字幕ファイル（captions.srt）をアップロードした
- [ ] YouTube の「改変または合成されたコンテンツ」の申告が必要かを、現在の案内で確認した

最後の項目について。YouTube には、実在の人物や出来事に見える合成コンテンツの申告の決まりと、
量産された似た内容の動画を収益化の対象外とする決まりがある。合成音声のナレーション自体は一般に問題にならないが、
**同じ型の動画を大量に出す場合は、1本ごとに固有の解説になっていることが大事**になる。
決まりは変わるので、ここに書いた内容を根拠にせず、公開の時点の YouTube の案内をユーザーに確認してもらう。
