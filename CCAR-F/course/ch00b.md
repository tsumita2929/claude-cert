# 試験の全体像

- 試験: CCAR-F ／ 試験の形式と出題範囲（分野1〜5）
- 確認日: 2026-11-16

## 本文

### 試験の形式

まずは試験の全体像です。

問題数は60問、試験時間は120分です。合格点は、100から1,000のスケールスコアで720です。72%正解という意味ではありません。形式は、択一式と複数選択式で、選ぶ数は問題に書いてあります。

**要点**
- 60問・120分
- 合格点はスケールスコア720（100〜1,000）
- 720は「72%正解」という意味ではない
- 択一式と複数選択式。選ぶ数は問題に書いてある

### 6つのシナリオのうち4つが出る

問題は、6つのシナリオのうち、無作為に選ばれた4つから出ます。各シナリオが、一連の問題の前提になります。6つは、カスタマーサポート解決エージェント、Claude Code によるコード生成、マルチエージェントリサーチシステム、Claude による開発者の生産性向上、継続的インテグレーションのための Claude Code、構造化データ抽出です。

**要点**
- 6つのシナリオのうち4つが無作為に出る
- 各シナリオが一連の問題の前提になる
- サポート、コード生成、リサーチ、開発者支援、CI、データ抽出

### 分野1、3、4で、全体のおよそ3分の2

分野は5つです。分野1、エージェントアーキテクチャとオーケストレーションが27%。分野2、ツール設計と MCP 統合が18%。分野3、Claude Code の設定とワークフローが20%。分野4、プロンプトエンジニアリングと構造化出力が20%。分野5、コンテキスト管理と信頼性が15%です。

最大の分野1に、分野3と分野4を合わせると、全体のおよそ3分の2になります。ここを厚めに学びましょう。

**要点**
- 分野1 エージェントアーキテクチャとオーケストレーション 27%
- 分野2 ツール設計と MCP 統合 18%
- 分野3 Claude Code の設定とワークフロー 20%
- 分野4 プロンプトエンジニアリングと構造化出力 20%
- 分野5 コンテキスト管理と信頼性 15%

### 業務の場面から、最も適切な対応を選ぶ

問題の多くは、業務の場面を示し、最も適切な対応を選ばせます。もっともらしいが劣る選択肢も並ぶので、なぜそれを選ぶのか、という判断の軸が大切です。

講座は、第1章と第2章で分野1、第3章で分野2、第4章と第5章で分野3、第6章と第7章で分野4、第8章で分野5を扱います。最後に、総復習があります。

**要点**
- 業務の場面から、最も適切な対応を選ぶ
- 用語の暗記より、判断の軸を持つ
- 第1・2章が分野1、第3章が分野2、第4・5章が分野3
- 第6・7章が分野4、第8章が分野5
